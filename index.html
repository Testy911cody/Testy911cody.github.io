How this is actually built

One domain, two kinds of app. /games is the multiplayer arcade rendered by Next.js. /apps is a catalog of standalone tools — several of them are separate codebases exported to static files and served from the same origin. That keeps one domain, one deploy, and no cross-origin auth juggling.

Deploys are opt-in. GitHub Actions runs QA on pushes, but the production Cloudflare upload only fires on an explicit [deploy] marker or a manual workflow dispatch. Cheap feedback on every commit; releases stay deliberate.

Guest-first. House Games rooms and PityParty campfires both work without an account. Sign-in adds persistence, it is not a gate at the front door.
