How it is built

  • One domain, two kinds of app. /games is the Next.js arcade; /apps are separate codebases exported to static files on the same origin.
  • Opt-in production deploys. CI runs QA on pushes; Cloudflare upload only on an explicit marker or manual dispatch.
  • Guest-first where it fits. Arcade rooms and PityParty work without an account; sign-in adds persistence.
  • Accessibility that fits the user. Talk Board exists because commercial AAC has no voice for Sudanese and Juba Arabic; community-recorded audio fills the gap TTS cannot.
